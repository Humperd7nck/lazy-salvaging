# Lazy Salvaging

RuneLite highlights for Merchant salvaging, sorting and inventory cleanup.

- Current task highlights and optional previews of the next task.
- Cargo hold tracking and crew assignment guidance.
- Keep, Drop, Alch and container storage choices for loot.
- Optional crystal extractor reminders.
- Custom highlight colors and a compact info panel.
- Optional left-click menu swaps; right-click options remain available.

## Setup

Supports salvaging with 1 or 2 crewmates. 

Open the cargo hold once each session to start tracking.

Set your loot choices in the plugin settings (Drop/Keep/Alch) and choose up to six seeds for the seed box. **Drop container overflow** highlights stored items for dropping when their container is confirmed full.

Toggling the plugin off and on clears session tracking and totals. Your settings are kept.

## Build

Use JDK 17. Run `./gradlew clean build` or `gradlew.bat clean build` on Windows. Run `./gradlew run` to launch RuneLite with the plugin.
